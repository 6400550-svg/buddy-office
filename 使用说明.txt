Buddy 办公室
==================

一间像素风的小办公室：你每开一个 Claude Code 会话（桌面 App、终端、VS Code 都算，
通过代理用的 DeepSeek / GLM 会话也算），办公室里就多一个小人坐到工位上。
你从他背后看过去，显示器正对着你——谁在忙、在干什么、谁在等你，扫一眼就知道。
某个小人需要你的时候（等你批准、问你问题、计划等你看），会转过身来举起手。

  · 每个小人：一个会话。桌牌上写着会话标题和当前在做什么、这一轮用了多久、用了多少 token
  · 点小人：跳到那个会话
  · 有人等你 / 一轮做完了：弹提醒，Dock 图标上有数字角标，菜单栏图标变成举手的小人

所有数据都只在本机读取，不联网、不上传。
只在 ~/.claude/settings.json 里加了一条「会话启动」hook（让它跟着 Claude 一起打开），卸载时会删掉。


安装
----
1. 双击「安装.command」。
   如果提示"无法打开，因为来自身份不明的开发者"：
   右键点「安装.command」→ 打开 → 再点「打开」。
   （或者打开「终端」，输入 bash 加一个空格，把「安装.command」拖进去，回车。）

2. 第一次会编译，大约 1～3 分钟。需要「命令行开发者工具」（没有的话会弹出苹果的安装窗口，
   装完再双击一次安装程序）。

3. 中途问一个问题：「要不要让 Buddy 办公室跟着 Claude 自动打开？」
   回答 Y（直接回车），就会在 ~/.claude/settings.json 里加一条 hook，之后每次开 Claude Code 会话，
   Buddy 办公室会在后台自己打开。改动之前会先备份成 settings.json.bak-日期-时间。

4. 装好后屏幕上出现一间像素办公室，程序放在「个人的 应用程序 文件夹」（~/Applications/Buddy 办公室.app），
   Dock 里有图标，菜单栏右上角也有一个小图标。第一次会遇到两个系统提示：
     · 通知：允许的话，有人等你批准 / 做完了会弹系统通知；不允许也行，会改用屏幕右上角的像素提示面板。
     · 自动化（控制「终端」）：第一次点小人跳到终端里对应的标签页时才会问。

装好之后没有会话的话，办公室是空的（桌子空着，地毯上有一块牌子「今天还没人上班」）。开一个 Claude Code 会话，就会有人走进来坐下。


三种形态（可以同时开，也可以只开一个）
----------------------------------
· 办公室窗口：完整的办公室，可以随意缩放窗口，会话多了自动排成几列几排。位置和大小会记住。
  关闭窗口只是收起，程序还在（Dock 里、菜单栏里都能再打开）。
· 小鱼缸：一个置顶的小窗，紧凑版的办公室。第一次出现在屏幕右上角；按住背景可以拖动（位置会记住）；双击背景回到办公室窗口（小鱼缸收起）。
  最多画 8 个人，再多的用右下角的「+N」牌子告诉你。
· 桌面宠物：没有墙和地板，小人直接坐在屏幕底部（Dock 上方），透明，不挡鼠标——
  只有鼠标碰到小人的时候才会被拦下（可以点他，其他地方的点击照常穿过去）。
  最多画 8 个人，再多的用最右边的「+N」牌子告诉你。

切换：办公室窗口标题栏右边有三个像素小按钮——缩成小鱼缸 / 开关桌面宠物 / 设置（对应的形态开着时，按钮是金色描边）；
      也可以用菜单栏图标 → 办公室窗口 / 小鱼缸 / 桌面宠物，或者「设置 → 形态」。
也可以按全局快捷键 ⌃⌥⌘B 开关办公室（默认关闭，在设置 → 形态 里打开）。
至少会保留一个入口（Dock 图标 / 菜单栏图标），不会把自己藏到找不到。


小人在做什么
------------
  敲键盘、快速敲键盘    改代码、写文件（快速敲是在写整个文件）
  身体前倾、手拿鼠标    读文件、看网页、搜索、操作浏览器 / 电脑（显示器里的内容也跟着变）
  手托下巴              在思考（想得久了会改成用笔轻敲桌面）
  在便签本上写字        列计划（TodoWrite / 做计划）
  靠着椅背喝水          命令跑了很久（Bash 长命令、盯日志）
  桌上出现小托盘 / 闹钟    发文件给你、定了闹钟
  小助手坐着带轮子的凳子从旁边滑进来    派了子代理（最多显示 3 个，再多显示 +N）
  转过身、举手、气泡里有钥匙   等你批准（气泡里是工具的图标）
  转过身、举手、气泡里有问号   有问题问你
  转过身、举着写字板    计划做好了，等你看
  伸个懒腰              一轮做完了
  两手一摊              被你打断了
  捂脸                  出错了
  显示器亮着屏保、低头打盹   空闲超过 10 分钟
  趴在桌上睡着、冒 zzz   空闲超过 45 分钟
  桌上插着一面小旗       这个会话有你还没看的新结果
  台灯亮着               在忙（夜里所有的灯都会亮）
  门口衣帽架上挂着他的外套    这个桌面会话已经收起（下班了）；桌子空着、显示器关着、桌牌变暗。它重新活跃起来，小人会走回这个工位
  窗外的天色、钟、白板上的「正」字   真实的时间；白板上按 5 笔一个「正」字，记着今天做完了几轮

小人的样子（发型、衣服、颜色、桌上的摆件）由会话身份决定，同一个会话每次都是同一个人；
右键点小人 →「换个造型」可以换一个。


点击、提醒、悬停
----------------
· 点小人：桌面 App 会话用深链直接跳到对应的会话；终端会话切到对应的终端标签页；
  VS Code 会话把 VS Code 带到最前。跳不了的时候右上角会有一条说明。
· 鼠标停在小人身上 0.25 秒：出一张卡片，写着标题、目录、模型、状态、本轮用时、token 明细等。
· 右键点小人：跳转 / 换个造型 / 隐藏这个 buddy（菜单里可以再显示回来；被隐藏的 buddy 不再提醒你）。
· 提醒（设置 → 提醒 里逐项开关）：
    · 等你批准、有问题问你、计划等你看：连续等了 1.5 秒才提醒，不会因为一闪而过的状态打扰你；
    · 一轮做完了：这一轮用了 30 秒以上才提醒（时间可调）；
    · 出错：默认不提醒；
    · 你正在看那个会话时不提醒（桌面 App：Claude 在最前且就是那个会话；终端 / VS Code：宿主 App 在最前）；
    · 同一个小人 20 秒内最多提醒一次；几个人同时在等你，合并成一条「N 位同事在等你」。
  系统通知没授权的时候，用屏幕右上角的像素提示面板 + Dock 角标 + 菜单栏举手图标兜底。
  提示音是运行时合成的 8-bit 短音，也可以改成系统提示音或关掉。


演示模式
--------
菜单栏图标 →「演示模式（看看所有动作）」：6 个假小人按剧本把上面所有状态演一遍
（进场、走路、思考、各种工具、等批准、提问、计划、派子代理、压缩、重试、出错、被打断、做完、打盹、睡着、离场……）。
想看看每个动作长什么样、或者截图 / 录屏的时候用。再点一次回到真实数据。


设置
----
菜单栏图标 → 设置…，有四页：形态（三种形态的显示、缩放、位置、菜单栏 / Dock / 快捷键）、
提醒、其他（空闲多久打盹 / 睡着、下班工位保留几个——这几项下次启动生效，「最多保留」调小立刻生效；隐私模式、跟着 Claude 一起收、开机启动）、
数据源诊断（现在读到了什么、ccmon hook 有没有装、系统通知状态、深链是否可用，可以测试深链、重新启用深链）；
「提醒」页里有「发一条测试提醒」。
· 隐私模式：桌牌、卡片、通知里隐藏全部细节（只写「会话」）。
· 跟着 Claude 一起收：Claude 退出、没有任何会话之后 60 秒，自己退出；Claude 重新打开就取消。
· 开机启动：登录时在后台打开。


需要注意
--------
· 如果 macOS 的 Gatekeeper 拦下了 App，右键 → 打开。
· 「自动化」授权在重新编译（重新安装）之后会再问一次。
· Claude 桌面 App 自己也可能发系统通知，可能和这里的提醒重复；不想重复就在「设置 → 提醒」里关掉「桌面 App 里的会话也提醒」。
· 装了 ccmon 的 hook（~/.claude/settings.json 里 monitor/hook.sh 那几项），小人的动作会更及时（工具一开始 / 结束就知道）；
  没装的话，靠会话记录和进程信息推断，会慢一点，但也能用。
· 只显示本机正在运行的 Claude Code 会话，网页版 claude.ai 的聊天不在里面。
· 不读你的提问内容（prompt）；界面里的文字只有会话标题、文件名、命令的前几个词这类元数据，
  想连这些也藏起来就开隐私模式。
· 不联网，没有任何遥测。


卸载
----
双击「卸载.command」：退出 App、注销开机启动、删除 ~/Applications/Buddy 办公室.app、
从 settings.json 里去掉那条 hook（只删它自己的，别的 hook 不动，同样会先备份）。
最后问你要不要连偏好设置一起删。


常见问题
--------
· 装好了但办公室里没有人：Buddy 办公室只显示「正在运行」的 Claude Code 会话；开一个会话，几秒内就会有人走进来。
  菜单栏图标 → 设置 → 数据源诊断 能看到它现在读到了什么。
· 点小人没有跳到对应会话：先看诊断页里「深链」是不是被停用了（连续几次没生效会自动停用）；
  终端会话需要「自动化」授权（系统设置 → 隐私与安全性 → 自动化）。
· 小人的动作有点滞后：没装 ccmon hook 时是这样，见上面「需要注意」。
· 想临时不看：关掉办公室窗口就行，程序还在后台跑（提醒照常）；要完全退出：菜单栏图标 → 退出。
· 想让它不再自动打开：设置里没有这个开关（它是 settings.json 里的那条 hook）；双击「卸载.command」，
  或者运行 python3 scripts/hook-merge.py uninstall。
